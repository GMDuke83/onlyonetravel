# Bildauftrag für ChatGPT — ONLYONE LUXURY TRAVEL

Diese Datei ist so gebaut, dass du sie **direkt an ChatGPT geben kannst**.
Jeder Prompt ist vollständig: Stil, Motiv und Verbote stecken bereits drin.
Du musst nichts anhängen und nichts zusammensetzen.

Es fehlen **12 Bilder**: 5 Regionen und 7 Hotelmotive.

---

## Kurzanleitung

1. Einen Prompt-Block kopieren, in ChatGPT einfügen, Bild erzeugen lassen.
2. Ergebnis unter dem angegebenen **Dateinamen** speichern.
3. Datei ins Repo legen:
   * Regionen → `public/images/hotels/`
   * Hotels → `public/images/hotels/`
4. Fertig — am Code ändert sich nichts, die Namen sind bereits verdrahtet.

**Wichtig zum Format:** Seitenverhältnis muss stimmen, sonst schneidet die App
mittig zu und es geht Motiv verloren.

| Gruppe | Seitenverhältnis | Zielgröße |
|---|---|---|
| Regionen | Hochformat 3:4 | 480 × 640 px |
| Hotels | Querformat 16:10 | 640 × 400 px |

Wenn ChatGPT diese Verhältnisse nicht exakt liefert: größer erzeugen lassen und
mit dem Befehl unter [Zuschneiden](#zuschneiden) mittig beschneiden.

---

## Was NICHT ins Bild darf

Steht in jedem Prompt schon drin, hier zur Kontrolle beim Sichten:

* keine Schrift, keine Beschriftung, kein Wasserzeichen, kein Logo
* keine Benutzeroberfläche, kein App-Screenshot, kein Handy-Rahmen
* keine Collage, keine Rahmen oder Ränder
* keine erkennbaren Gesichter, keine Personen im Vordergrund

Bildgeneratoren setzen sonst gern Schrift oder Interface-Elemente ins Bild.
Ein Bild mit eingebrannter UI ist unbrauchbar.

## Zuschneiden

Falls die erzeugten Bilder nicht exakt 3:4 bzw. 16:10 sind — erst skalieren,
bis der Rahmen sicher gefüllt ist, dann mittig beschneiden. So entstehen keine
Ränder:

```bash
# Region (Hochformat 3:4)
ffmpeg -i quelle.png \
  -vf "scale=480:640:force_original_aspect_ratio=increase,crop=480:640" \
  -quality 80 public/images/hotels/region-side.webp

# Hotel (Querformat 16:10)
ffmpeg -i quelle.png \
  -vf "scale=640:400:force_original_aspect_ratio=increase,crop=640:400" \
  -quality 80 public/images/hotels/h05.webp
```

Richtwert je Datei: 25–60 KB. Deutlich darüber → `-quality 70`.
