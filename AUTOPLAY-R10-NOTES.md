# ONLYONE r10 — Intro Autoplay

- Intro starts muted automatically by default.
- Manual Start Journey button is hidden during the normal path.
- The fallback button is only armed after 6.5 seconds with no video progress, or immediately on a hard media error.
- On iOS, the first ordinary touch can resume a blocked muted video invisibly.
- Audio remains explicit through the sound control because Safari requires a user gesture for audible media.
- Existing r9 living-image animations and media performance optimizations are preserved.
